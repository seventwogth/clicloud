# clicloud v0.1.0

First release of the terminal music player for Linux, macOS and Windows.

- Search and play tracks; browse artists, playlists and track stations.
- Keep local favorites, import public profile likes, and restore the playback queue.
- Cache tracks for offline playback; use HTTP or SOCKS proxies, including Tor.
- Choose terminal themes, cover rendering, and English, Russian or Japanese.
- English is the default on first launch, including command-line help. Existing
  language settings are preserved.
- Windows player IPC supports simultaneous commands and playback events.
- Direct playback without a cache correctly bypasses proxy settings.
- Library updates from multiple clients and imports are serialized. Damaged
  libraries are preserved, and save failures are reported on exit.

## Installation

Download the archive matching your system and verify it against `SHA256SUMS`.
Extract it and put `clicloud` (or `clicloud.exe`) on PATH. Install `mpv` and
`yt-dlp` separately, then run `clicloud doctor` followed by `clicloud`.
The archive includes English and Russian instructions and example settings.

macOS marks a downloaded binary as quarantined and refuses to start it; clear the
mark once with `xattr -d com.apple.quarantine clicloud`. The Windows binary needs
no Visual C++ redistributable.

| Archive target | System |
| --- | --- |
| x86_64-unknown-linux-gnu | Linux x86_64, glibc 2.35+ (Ubuntu 22.04+) |
| aarch64-apple-darwin | macOS on Apple Silicon |
| x86_64-apple-darwin | macOS on Intel |
| x86_64-pc-windows-msvc | Windows x86_64 |

## Known limitations

clicloud is an independent project, not affiliated with SoundCloud or endorsed
by it. SoundCloud access depends on yt-dlp, network access and track availability.
Account login and two-way synchronization are not supported. Some tracks provide
only previews. Media keys through MPRIS are available only on Linux with mpv-mpris.
The binaries are not code-signed or notarized. Automated playback checks decode
audio without an audio device; they do not verify speaker output.
