Color themes in the format of [Ghostty](https://ghostty.org), built into clicloud.

The files are unmodified copies of themes that ship with Ghostty, which takes
them from [iTerm2-Color-Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes)
(MIT License, Copyright (c) 2011-present Mark Badolato and contributors).

To add one, copy its file here and list it in `BUILT_IN` in `src/theme.rs`.
